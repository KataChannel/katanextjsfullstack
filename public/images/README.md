# Images Directory

## Required Images for /ve-innerbright page

Please add the following image to this directory:

### Hero Section
- **chloe-quy-chau.jpg** (or .png)
  - Recommended size: 600x800px minimum
  - Format: JPG or PNG with transparent background preferred
  - Content: Professional photo of Chloe Quý Châu (trainer/coach)
  - Position: Will be displayed on the right side of the hero section
  - Style: Should show the person in professional attire

## How to add the image

1. Save your image file as `chloe-quy-chau.jpg` or `chloe-quy-chau.png`
2. Place it in `/public/images/` directory
3. The page will automatically display it

If the image is not found, the section will still work but the image area will be empty.
